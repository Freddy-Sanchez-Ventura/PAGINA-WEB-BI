REVIT

3. Estructura del modelo

Guía técnica para comprender cómo usar Revit con criterio BIM, estructura de información y enfoque profesional.

Revit BIM Modelado Datos

La estabilidad de un proyecto en Revit depende mucho de su estructura base. Si niveles, ejes, fases, vistas y organización del navegador están mal planteados, el resto del trabajo se vuelve más frágil.

Componentes estructurales del archivo

Niveles

Definen alturas y referencias para gran parte de los elementos del proyecto.

Ejes

Ordenan el replanteo, la lectura técnica y la ubicación de elementos estructurales o arquitectónicos.

Fases

Permiten separar estados del proyecto como existente, demolición y nueva construcción.

Vistas

Organizan producción, revisión, tablas y documentación final.

Buenas prácticas

  • Nombrar niveles de forma consistente.
  • Crear vistas según disciplina, etapa o paquete de entrega.
  • Usar plantillas de vista para mantener coherencia gráfica.
  • No mezclar información temporal o de revisión sin una lógica clara.
Un proyecto ordenado desde la estructura base cuesta menos de mantener y documentar.
