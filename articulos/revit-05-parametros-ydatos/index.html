REVIT

5. Parámetros y datos

Guía técnica para comprender cómo usar Revit con criterio BIM, estructura de información y enfoque profesional.

Revit BIM Modelado Datos

Los parámetros convierten un modelo geométrico en una base de datos útil. Gracias a ellos es posible clasificar, etiquetar, filtrar, programar tablas y automatizar tareas.

Tipos más usados

TipoUso
De sistemaPropiedades nativas del elemento.
De proyectoDatos propios del archivo actual.
CompartidosDatos que pueden usarse en varias familias, etiquetas y proyectos.
GlobalesControl de relaciones dimensionales o condiciones generales.

Buenas prácticas

  • Crear solo los parámetros que tengan una función real.
  • Nombrarlos con criterios consistentes.
  • Definir cuándo se llenan y quién es responsable de cada uno.
  • Evitar usar texto manual donde debería existir un parámetro.

Aplicaciones directas

Tablas

Controlar cantidades, tipos, estados y codificaciones.

Filtros

Resaltar elementos según sistema, disciplina, fase o condición.

Automatización

Leer y escribir datos desde Dynamo, API o exportaciones a Excel.
