5. CDE y gestión documental

Contenido estructurado para entender la metodología BIM de forma real, clara y aplicable en proyectos de diseño, coordinación, construcción y operación.

BIM Gestión de información Coordinación Calidad

El Common Data Environment es el entorno donde la información se crea, se comparte, se revisa y se publica. No es solo una carpeta común; es una estructura controlada que evita pérdidas, duplicidades y versiones contradictorias.

Qué debe garantizar un CDE

  • Trazabilidad de archivos y revisiones.
  • Permisos claros para crear, revisar, publicar y archivar.
  • Estados de la información entendibles por todo el equipo.
  • Un solo origen confiable para documentos y modelos vigentes.

Estados habituales

Trabajo

Información en desarrollo interno. Aún no está lista para ser usada por otros equipos.

Compartido

Información disponible para coordinación o consulta entre disciplinas.

Publicado

Información aprobada para emisión, construcción o uso contractual.

Archivado

Historial preservado para trazabilidad, sin confundirse con el contenido vigente.

Problemas comunes sin CDE real

  • Envío de archivos por chat o correo sin control de versión.
  • Documentos vigentes mezclados con revisiones antiguas.
  • Modelos que se usan para coordinar sin haber sido aprobados.

Buenas prácticas

  • Estructura de carpetas consistente.
  • Nomenclatura obligatoria de archivos.
  • Registro de emisiones y revisiones.
  • Definir quién puede publicar y bajo qué criterios.
Si dos personas no pueden identificar fácilmente cuál es el archivo vigente, el CDE no está cumpliendo su función.
